# 🍦📊 Prevendo Vendas de Sorvete com Machine Learning

Este projeto tem como objetivo prever a demanda de sorvetes com base na temperatura do dia, utilizando técnicas de Machine Learning. A análise foi feita a partir de frases reais que simulam o comportamento de vendas em diferentes condições climáticas.

## 📝 Sentenças analisadas

As seguintes frases foram utilizadas como entrada para a IA:

- Hoje a temperatura está alta, esperamos vender muitos sorvetes!
- Dias frios costumam ter vendas mais baixas de sorvete.
- Com previsão de calor intenso, a produção precisa ser dobrada.
- Temperaturas amenas geram demanda moderada por sorvetes.
- A previsão do tempo indica 35°C, ótimo para vendas!
- Com chuva e clima nublado, as vendas tendem a cair.

## 🧠 Processo de análise

A IA analisou as sentenças e identificou padrões de linguagem que indicam correlação entre temperatura e volume de vendas. Utilizamos um modelo de regressão simples para prever a quantidade de sorvetes vendidos com base em dados históricos de temperatura.
